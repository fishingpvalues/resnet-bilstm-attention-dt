# Changelog

All notable changes to the ResNet-BiLSTM-Attention Digital Twin project will be documented in this file.

## [1.0.0] - 2025-04-21

### Added
- Initial release of the ResNet-BiLSTM-Attention Digital Twin framework
- ResNet-BiLSTM-Attention model implementation
- Decision Tree baseline model
- Traditional hypothesis testing with averaging p-values
- Cauchy Combination Test (CCT) implementation
- Identical data testing framework
- Comprehensive visualization tools for hypothesis test results
- UV package manager support for reproducible environments
